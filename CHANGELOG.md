# Changelog

All notable changes to Sam & Dario are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [semantic versioning](https://semver.org/).

## [0.1.0] - 2026-11-25

First public release.

### Added

- Claude Code (left) and Codex (right) side by side in tmux, in your project folder, with automatic relays between them until an agreement, a decision for you, or the relay limit.
- Cross-reading: before asking you to decide, each assistant reads the other's view.
- A 16-bit scene starring Dario (Claude) and Sam (Codex), with scrollable speech bubbles.
- Clickable status bar buttons, manual relays, questions for both, and agreement export to Markdown.
- One team per project: first names, a shared charter in `AGENTS.md`, and remembered answers.
- Installation as a Python package with a `samdario` command (pipx recommended).
- Guides in English and French.
